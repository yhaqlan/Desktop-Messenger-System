DESKTOP MESSENGER - WINDOWS BUILD PACKAGE

No Windows executable is included because this Linux generation environment cannot validate a native Windows PyInstaller build. The reference archive also contained no usable application executable.

To create the executable on Windows:
1. Copy the complete submission to Windows.
2. Open Command Prompt in the Published directory.
3. Run build_windows.bat.
4. Test registration, login, database creation, LAN port 8765, relay port 9876, reconnect, pending messages, and encrypted round trips on two Windows computers.

Do not submit an EXE until that validation has been completed.
